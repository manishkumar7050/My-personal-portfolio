Explainable AI · NLP In Development

TrustLens AI

See Beyond the Stars.

Problem: Online reviews can look suspicious, but it is hard to judge them fairly, and many tools just give a verdict without showing why.

Approach: Show observable evidence instead of declaring a review or business fake, explain the method behind each finding, and be clear about the limits of the data.

Planned checks (design goals, not all finished)

  • Exact duplicate review detection
  • Similarity analysis for possibly related reviews
  • Generic wording patterns
  • Review timestamp analysis
  • CSV review import and findings export

Tech stack (MVP, in development): HTML, CSS, JavaScript, Python, Flask, Pandas, NumPy, Scikit-learn

My contribution: Contributed to the project concept, UI/UX design, frontend development, feature planning, and presentation. Focused on making review analysis understandable through clear evidence and transparent explanations.

AI · Civic Technology Team Project · Hackathon

CivicPulse AI

HackBIOS 2026 · SSTC, Bhilai · Team NexVanta

Problem: Civic complaints often arrive as many separate reports, so related issues are scattered and it is hard to see which ones need attention first.

Idea: AI-assisted complaint analysis and tracking that groups related reports, looks at the available evidence, and helps prioritize issues.

What was built: A working prototype with a civic complaint dashboard, report submission, report management, issue grouping, and demo data. It organizes related complaints using similarity-based, rule-driven demo logic and shows issue summaries and priority information. Live AI processing through the Gemini API was optional and depended on API configuration; the demonstrated version ran in demo mode.

Tech stack

  • Frontend: React.js, HTML, CSS, JavaScript
  • Backend: Node.js
  • AI integration: Google Gemini API integration in the codebase; demo mode used simulated, rule-based analysis
  • Data storage: Local JSON storage

My contribution: Contributed to idea development, project planning, frontend development, UI presentation, and preparing the project presentation for HackBIOS 2026 as part of Team NexVanta.
